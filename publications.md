# Publications

## Media analysis

Elaine Zhang, Hillary Liu, **Shixuan Lin**, Qisong Zhou, Siranush Kostanyan, and Andres Fortino. **Navigating Ethical Challenges in Media: AI Tools for Detecting Harmful Narratives.** 2025 IEEE Integrated STEM Education Conference (ISEC).

[Publication DOI](https://doi.org/10.1109/ISEC64801.2025.11147198)

The [media-analysis repository](https://github.com/shixuanlin1/unicc) contains a Streamlit application and a Dify workflow export associated with this area of my project work. Its public code snapshot has a narrower scope than the complete research project: it provides an inspectable application workflow rather than the paper's complete training and evaluation artifacts.
